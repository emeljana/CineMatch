# CineMatch

CineMatch är en React-app byggd med Vite.

## Kom igång

Installera beroenden:

```bash
npm install
```

Starta utvecklingsservern:

```bash
npm run dev
```

## Mappstruktur

Projektet ska följa den här strukturen under `src/`:

```txt
src/
├── api/          # API-klienter och HTTP-konfiguration
├── assets/       # Bilder, ikoner och andra statiska resurser
├── components/   # Återanvändbara React-komponenter
├── pages/        # Sidkomponenter/vyer
├── routes/       # Routing och route-konfiguration
├── services/     # Affärslogik och externa tjänster
├── styles/       # Globala stilar, variabler och CSS-moduler
├── App.jsx       # Appens rotkomponent
├── main.jsx      # Entrypoint för React
├── App.css       # Appspecifika stilar
└── index.css     # Globala grundstilar
```
